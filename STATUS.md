## Готово

- главная по продающей схеме: hero → почему вещь плохо продаётся → услуги → «исходник → карточка» → задачи клиентов → сверка деталей → почему Елена → **2 кадра бесплатно** → как работаю → цены → вопросы → контакт;
- главное действие везде одно: «Получить 2 кадра бесплатно» (шапка, hero, блок пробы, цены, липкая кнопка на телефоне после первого экрана);
- сцены прокрутки (от 1024 px и высоты 600 px): hero собирает 18-кадровую воронку вокруг исходника; горизонтальная лента 6 работ; стопка карточек с запросами клиентов; сверка деталей по шагам; линия процесса рисуется при прокрутке; появление блоков;
- без JavaScript, при reduced motion и на телефоне все сцены сразу в финальном виде;
- 17 реальных работ: `/works` с фильтром по типу одежды, `/works/[slug]` с исходниками, запросом клиента, телефоном-каруселью (свайп, кнопки, стрелки) и всеми кадрами;
- 228 кадров переведены в WebP скриптом `scripts/import-works.mjs` (12,7 МБ); выбор кадров в `scripts/works-import.json`; кадры с чужими логотипами исключены;
- старые адреса `/cases/*` и `/works/atelier-in-motion` перенаправляются;
- превью на GitHub Pages: `.github/workflows/preview.yml`, статичная сборка с `NEXT_PUBLIC_BASE_PATH=/portfolio-elena`;
- typecheck, lint, production build проходят; Playwright: 56 passed, 4 skipped (сцены только для desktop), 0 failed на 375/768/1024/1440.
