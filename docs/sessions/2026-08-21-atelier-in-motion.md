## Реализация

- новая Server Component главная и небольшие client-islands для scroll, swipe, сравнения и IntersectionObserver;
- desktop hero использует обычную прокрутку браузера, sticky-сцену и экономный `requestAnimationFrame` только при изменении scroll;
- mobile hero использует ручной swipe, кнопки, клавиатуру и видимый счётчик;
- reduced motion показывает устойчивый contact sheet без scroll-анимации;
- no-JS версия сохраняет изображения, тексты, навигацию и обе стороны сравнения;
- один LCP-ресурс имеет `preload`, остальные изображения lazy-loaded через Next Image;
- добавлена флагманская история `/works/atelier-in-motion`.
