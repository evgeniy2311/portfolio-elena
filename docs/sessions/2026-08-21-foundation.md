# Сессия: фундамент проекта

Дата: 2026-08-21

## Запрос

Подготовить фундамент будущего адаптивного и необычного сайта-портфолио Елены Бадьиной, исследовать лучшие практики, предложить несколько направлений, объяснить экспорт Telegram и правильно организовать папку для работы Codex и Claude.

## Выполнено

- исследованы интерактивные портфолио и сайты дизайнеров карточек WB/Ozon;
- изучены официальные каталоги Framer, Readymag и Webflow и зафиксированы их роли для прототипа/production;
- сформированы три направления: Runway Editorial, Commerce Atelier, Living Moodboard;
- рекомендован гибрид A+B;
- описаны продукт, аудитория, сценарий и структура сайта;
- создан шаблон подготовки кейсов в Telegram;
- подтверждена возможность экспорта Telegram Desktop в JSON с медиа;
- подготовлена безопасная методика MPSTATS для будущих доказательств;
- создан набор проектных документов и правила межсессионной передачи.

## Принятые решения

- не начинать код до выбора концепции;
- использовать `AGENTS.md` как единый источник инструкций;
- предпочесть Telegram JSON для импорта;
- не публиковать метрики без контекста и проверки.

## Следующий шаг

Получить реакцию Елены на три концепции и зафиксировать выбранное направление в `docs/DECISIONS.md`.
