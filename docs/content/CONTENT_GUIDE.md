# Как подготовить портфолио

## Лучший формат сообщения в Telegram

Одна работа = одно отдельное сообщение или один альбом. Подпись лучше заполнять по шаблону:

```text
#кейс #одежда #wildberries

Название: [бренд / тип товара]
Площадка: [WB / Ozon]
Категория: [куртка / платье / костюм / ...]
Год: [2025]

Задача:
[что было нужно клиенту]

Проблема:
[что не работало или чем нужно было выделиться]

Моё решение:
[идея, композиция, визуальная логика, последовательность слайдов]

Мой вклад:
[анализ / тексты / ретушь / дизайн / нейрофото / другое]

Результат:
[только известные факты; если цифр пока нет — так и написать]

Показы / переходы / CTR:
[значения, период и источник; если есть данные до/после — обе пары]

Артикул:
[WB/Ozon ID, если можно публиковать]

Дата публикации нового дизайна:
[хотя бы примерно]

Можно публиковать бренд и цифры: [да / нет / уточнить]
```

## Какие файлы прикладывать

- финальные слайды в исходном порядке;
- обложку карточки отдельно;
- исходные фото товара, которые использовались для генерации: общий вид, карманы, молнии, планки, капюшон, швы, фактура и другие конструктивные детали;
- вариант «до», если есть;
- скрин выдачи или карточки на площадке;
- исходное фото, если оно помогает показать вклад;
- статистику только при наличии разрешения;
- скриншот/выгрузку показов, переходов и CTR из кабинета продавца;
- отзыв клиента отдельным изображением или точным текстом.

Не присылать только длинный коллаж: для сайта нужны отдельные изображения, чтобы адаптивно собирать галерею.

Исходные фото товара и старая карточка «до редизайна» — разные материалы. Исходники показывают, что получила Елена перед генерацией; «до» показывает прежний публичный дизайн. Для каждого исходника отдельно подтвердить разрешение на публикацию. Если разрешённых исходников нет, публичная страница не показывает пустой блок или сообщение об их отсутствии.

## Что отметить для проверки точности

Для кейсов с нейровизуалом перечислить детали, которые Елена сверяла вручную: форма и расположение карманов, молния, ветрозащитная планка, капюшон, швы, стёжка, фурнитура, фактура, цвет, пропорции и посадка. Публично показывать только реально проверенные признаки и по возможности прикладывать парные crop-фрагменты «исходник / финальный кадр».

## Минимум для полноценного кейса

- 5–10 финальных слайдов;
- короткая задача;
- 2–4 предложения о решении;
- точный список вклада Елены;
- площадка и категория;
- один результат: качественный или количественный;
- для кейса обложки желательно: показы, переходы и CTR с периодом;
- разрешение на публикацию.

## Как выбирать главные работы

Для первой версии нужны 4–6 кейсов, которые вместе показывают диапазон, но не размывают специализацию:

1. самый сильный fashion-кейс;
2. кейс с лучшим измеримым результатом;
3. сложный редизайн «до/после»;
4. серия для нескольких цветов/SKU;
5. кейс с продуманной воронкой слайдов;
6. экспериментальная или особенно любимая работа.

## Чего не должно быть в публичном тексте

- неподтверждённых «увеличила продажи в N раз»;
- данных клиента без разрешения;
- слова «топ» без категории, периода, площадки и источника;
- длинных общих фраз вроде «индивидуальный подход и высокое качество»;
- обещаний результата, который зависит не только от дизайна.

## Сколько изображений отдавать на один кейс

Если для артикула сделано 15 слайдов, для первого отбора прислать можно все 15, но отметить приоритетные. На публичной странице обычно достаточно:

- 6–8 основных изображений;
- до 2 доказательных изображений: «до» и скрин выдачи/аналитики;
- обложка может повторно использоваться на главной и в кейсе.

Предпочтительный набор: обложка, ключевое преимущество, посадка/образ, деталь, функциональное преимущество, размер/инструкция и lifestyle/закрытие возражения. Финальное число проверяется на визуальном прототипе.
