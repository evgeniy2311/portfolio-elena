# Замечания владельца к v3 (2 ноября 2026)

Источник: сообщение владельца в чате после публикации v3. Скриншоты лежат в рабочей папке задачи (не в репозитории).

1. **Первый экран, плашка «Сверка деталей».** «Вот баг на карточке, как-то сверка деталей где-то не там находится, непонятно почему. Сайт должен быть динамичный, продуман для всех видов там мониторов». На скриншоте плашка с пальто наезжает на стену работ и на текст, под первым экраном видна пустая бежевая полоса.
2. **Лента «С чем работаю».**
   - «надо сделать, чтобы можно было прямо руками их здесь переворачивать» (листать руками, мышью и пальцем, заметно и удобно);
   - фото в рамке по центру становится ярче: «надо, чтобы все фотки были яркие уже заранее, не надо, чтобы была блёклость на них»;
   - «Скорость передвижения должна быть быстрее... минимум в два раза».
3. **Обувь.** Сгенерировать через GPT минимум пять разных вариантов модных ярких кроссовок в формате референса: кроссовок висит на шнурках в руке, второй лежит ниже, студийный фон (фон можно менять). Без Adidas и других чужих брендов. «Яркие, прямо какие-то кроссовки, которые бросаются в глаза».
4. **Блок «Обо мне».** «Этот вариант нам не нравится. Он смотрится дёшево... можно весь блок переделать». Текст «Я Елена, делаю визуал для карточек одежды» без продолжения: «И чё дальше-то?». Владелец упоминает старый сайт Елены (ссылки пока нет).
5. **Строка «Делаю кадры для Wildberries» с кнопкой паузы.** «Непонятно, что это за кнопка, она как будто никак не влияет... Картинка слева не двигается... нужен лучше слайд... Предложи несколько вариантов решений. Может быть, его вообще убрать?»
6. **Цвета.** По референсу презентации: сочетание серого и оранжевого. «Оранжевый можно чуть ярче, а серый даже чуть насыщеннее, чтоб дорого смотрелось». Стиль сайта не менять, только цветовую гамму. «Давай попробуем, посмотри, как будет смотреться».
